# Dog Poop Detection Project

This repository contains two main components:

## 1. DeepLabCut Project (`poop_project-munneth-2025-06-25/`)
Contains the DeepLabCut pose estimation project for tracking dog behavior and detecting poop events.

## 2. UltraAnalytics (`Ultraanlytics/`)
Contains the video classification system for detecting poop in security camera footage using YOLO models.

### Project Structure:
```
DLC/
├── poop_project-munneth-2025-06-25/  # DeepLabCut pose estimation
└── Ultraanlytics/                    # Video classification system
    ├── ultraanalytics/               # Main classification code
    ├── deeplabcut/                   # DeepLabCut integration
    ├── datasets/                     # Training datasets
    └── yolovenv/                     # Python virtual environment
```

## Getting Started

1. For DeepLabCut pose estimation, navigate to `poop_project-munneth-2025-06-25/`
2. For video classification, navigate to `Ultraanlytics/ultraanalytics/`
